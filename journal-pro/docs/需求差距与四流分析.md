# 会计调研表 → 系统需求差距与「四流」分析（V2.14）

> 依据：`D:\日记账\会计调研.xlsx`（Sheet1，13 行 × 7 列，85 个非空单元格）。
> 表格结构：A 考试类型 / B 考试科目 / C 核心详细子科目 / D 数据流 / E 价值流 / F 工作流 / G 执行流。
> 数据行共 **11 个科目**（第 2–12 行）；第 13 行标注"内容由AI生成"。

## 1. 先校正一个认知：这张表不是功能清单

它是**会计职业能力知识体系**（中级 3 科、高会 1 科、CPA 专业 6 科、CPA 综合 1 科），用四列描述每个能力域：

| 流 | 表格原意 | 在本系统里对应什么 | 系统现状 |
|---|---|---|---|
| **数据流 D** | 数据从业务端采集 → 会计加工 → 标准财务信息 | 表结构 / API / 数据血缘 / 单据→凭证→账→报表链路 | 主链路完整；**复杂业务的加工层大量缺失**（长投、租赁、递延所得税、合并抵消） |
| **价值流 E** | 为管理、纳税、融资、决策提供价值 | 指标、报告、预测、风险提示、合规判定 | 有比率/税负率/预测/压力测试；**缺资本成本、EVA、杜邦、期权、估值、战略价值指标** |
| **工作流 F** | 制单→审核→过账→计提→对账→结账→编报的闭环 | 任务状态机、审批、向导、待办、期间控制 | 有主闭环与 4 条流程向导；**缺全面预算闭环、投融资立项→复盘、内控评估→整改、审计业务承接→报告等 6 条闭环** |
| **执行流 G** | 会计人员具体动作（编分录、计提、抵消、申报…） | 可执行的写操作 + 生成凭证 + 留痕 | 有折旧/摊销/坏账/结转/算薪；**缺约 40 类执行动作** |

**关联性结论**：现有系统把「数据流」做得很实（260 个接口大多是查询/台账），但「价值流→工作流→执行流」三层是断的——很多数据能查到，却没有对应的决策模型、流程闭环和执行动作。这正是调研表揭示的核心问题。

## 3. 四流贯通检查（当前断在哪里）

| 检查项 | 结果 |
|---|---|
| 单据 → 凭证 → 账 → 报表（数据流主线） | ✅ 贯通 |
| 报表 → 指标 → 决策建议（价值流） | 🟡 有指标与预测，缺资本成本/估值/杜邦/EVA |
| 决策 → 流程闭环（工作流） | ❌ 预算、投融资、内控、审计、税务稽查 5 条闭环未建 |
| 流程步骤 → 可执行动作 + 凭证 + 留痕（执行流） | 🟡 仅折旧/摊销/坏账/结转/算薪/申报测算 |
| 四流是否可互相追溯 | ❌ 目前无「知识点 → 数据 → 价值 → 流程 → 动作」的关联模型 |

**完整度估计**：按 C 列拆分为 **191 个知识点**（按顿号/斜杠细分）入库后，系统自动统计覆盖度见「能力图谱」页；空缺项以缺口清单为准。
