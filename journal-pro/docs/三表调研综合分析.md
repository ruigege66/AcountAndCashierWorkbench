# 三份会计调研表综合分析与系统映射（V2.16）

> 依据：`会计调研.xlsx`（表1，4 流）、`会计调研2.xlsx`（表2，7 流）、`会计调研3.xlsx`（表3，岗位视角）。
> 三表逐格读取，未修改任何原始文件。

## 1. 三张表的关系（递进，不是并列）

| 表 | 行 × 列 | 视角 | 回答的问题 |
|---|---|---|---|
| 表1 | 11 行 × 7 列 | 考试科目 | 一项工作有哪 **4 条流**：数据 / 价值 / 工作 / 执行 |
| 表2 | 11 行 × 10 列 | 考试科目（细化） | 同一项工作实际要跑通 **7 条流**：**+ 资金流 / 管控流 / 合规流**；每格是可对照系统的动作链 |
| 表3 | 5 行 × 12 列 | **岗位** | **谁**来跑这 7 条流、按什么 **能力进阶梯度**（初级→中级→高阶） |

**关键结论**：表2 是表1 的超集与细化（四流 → 七流），表3 引入了**执行主体**维度。三者合并后，完整需求模型是四维的：

> **工作（11）× 七流（7）× 岗位（5）× 能力级别（3）**

系统不能只按「功能菜单」组织，必须能回答：某岗位在某一级能力下，做某项工作时，七条流分别走到哪一步、系统里点哪里、受什么管控、依据哪条法规。

## 2. 七流的系统含义（表2 新增三条是重点）

| 流 | 表2 核心内容（摘要） | 系统映射 |
|---|---|---|
| 数据流 | 原始单据→系统录入→明细账→总账→期末计提→对账→单体→合并抵消→报表附注 | 业务单据 / 凭证 / 账簿 / 财务报表 / 高阶核算 |
| **资金流**（新） | 收付指令→网银/银企直连→资金日记账→余额核对→余额调节表→资金日报 | 现金银行日记账、银行对账、资金日报、外部协同批量付款 |
| 工作流 | 业务发生→初审→制单→审核→过账→计提结转→财产清查→核对→结账→编报→审核→归档 | 11 个工作台的**流程步骤状态机** |
| 执行流 | 审核凭证、编分录、计提折旧摊销减值、结转成本、往来清账、银行对账、编合并抵消、出四大报表 | 高阶核算 14 项 / 税务中心 / 期末结账 / 外部协同 |
| **管控流**（新） | 不相容岗位分离、分级授权审批、大额资产审批、减值审批、结账审批、报表多级审核、定期监盘 | 职责分离 `separate_duties`、RBAC、安全中心、内控闭环、审计哈希链 |
| 价值流 | 业务信息→标准核算→准确财务数据→支撑申报/融资/经营分析→降低信息不对称 | 经营分析报告、财务比率、预测、杜邦/EVA 等模型 |
| **合规流**（新） | 会计准则、税法、公司法、证券法、票据法、破产法、档案管理办法、内控基本规范 | 凭证合规体检、内控合规、审计链、税务申报测算、合规义务倒计时 |

**新增三流带来的改变**：
- 资金流把「账务正确」和「钱真的动了」分开核对——以前系统偏账务，现在明确要求日记账 / 余额调节 / 资金日报与账套联动；
- 管控流把「谁可以做什么」变成一等需求，不再只是安全设置；
- 合规流把「依据哪条法规」写进每个流程，系统提供检查点但不替代法定审核。

## 3. 岗位维度（表3）

5 类岗位 × 7 流核心动作 × 3 级进阶，共解析 **171 个岗位流节点、15 条进阶要求**：

| 岗位大类 | 典型细分岗位 | 系统里的落点 |
|---|---|---|
| 财务核算类 | 应收应付 / 成本 / 总账 / 合并报表会计 / 核算主管 | 账务核算、准则核算工作台 |
| 审计类 | 外审 / 内审 / 内控专员 / 审计主管 / 风控 | 内部审计、审计鉴证工作台 |
| 税务管理类 | 税务专员 / 主管 / 经理 / 国际税务 / 筹划顾问 | 全税种管理工作台、税务中心 |
| 财务管理·管理会计类 | 财务分析 / 预算 / 成本 / 资金 / BP / 主管 | 财务与预算、成本与估值工作台、高阶模型 |
| 高阶财务管理类 | 财务经理 / 总监 / 集团负责人 / CFO 助理 | 集团与战略财务、重大项目综合工作台 |

每个岗位页显示：七流各自的核心动作、初级→中级→高阶的能力要求、以及关联的工作台入口。

## 4. 四维关联性与完整度审视

- **关联性**：工作 × 七流已按步骤横向对齐（一步同时给出数据产物、执行动作、系统入口）；岗位通过「对应考试科目」关联到工作；能力级别决定该岗位应看到的工作台深度。
- **完整度**：表2 解析出 **564 个工作流节点**（11 工作 × 7 流），表3 解析出 **171 个岗位流节点**。当前 321 个接口里，与七流建立了明确映射的约 **43/79 个工作流步骤**（V2.15 口径），管控流与合规流中「上市公司信息披露 / 破产清算 / 集团资金池」等仍标为部分支撑或待建。
- **适用性**：
  - 单机企业账套可完整实现：核算、资金日记账、预算模型、税务计算、审计底稿、合规检查点；
  - 需企业资质/签约：银企直联、数电票直连、集团资金池；
  - 主体或业务性质不同、明确裁剪：政府会计、民非会计、行政事业单位预算；
  - 属外部司法/资本市场程序、仅保留清单：证券发行、破产清算、IPO 承销、涉外诉讼。

## English Summary (see `Survey_Analysis_EN.md` for the full version)

The three workbooks are progressive, not parallel: Survey 1 defines 4 flows per exam subject; Survey 2 extends them to **7 flows** (adding **fund flow, control flow, compliance flow**) with executable action chains; Survey 3 adds the **job-role** dimension (5 role families × 7 flows × 3 career levels). The resulting requirement model is **11 jobs × 7 flows × 5 roles × 3 levels**.

The system now exposes 7 flow tabs per workbench, a role/career page, control-point mapping (segregation of duties, RBAC, approval), a compliance register of 43 extracted legal references, and a one-click demo dataset (51 records / 30 tables) that can be fully removed without touching real data. 10 regression suites / 326 assertions pass.
