# 会计出纳全流程管理系统（Journal Pro）

<div align="right">

**[🇬🇧 English](README_EN.md) ｜ 简体中文**

</div>

单机可部署的会计 + 出纳一体化系统：**Python 标准库 + SQLite，零第三方依赖**。
覆盖业务单据 → 审批 → 自动凭证 → 过账 → 日记帐 → 对账 → 期末结账 → 三大报表 → 经营分析与预测的完整链路，内置内控合规（不可变账本、审计哈希链、职责分离）。

> 版本：V2.10 ｜ 前后端分离（原生 JS SPA + REST API）｜ 数据库：SQLite（WAL）｜ 测试：5 套回归 203 项断言 + pre-commit + CI

---

## 功能总览

### 核心会计与出纳

| 模块 | 说明 |
|---|---|
| 业务单据 | 付款申请 / 收款单 / 备用金借款 / 费用报销，审批后自动生成凭证 |
| 凭证管理 | 制单-审核-过账职责分离、红字冲销代替删除、借贷平衡强校验、附件挂接 |
| 日记账 | 现金 / 多银行账户，逐笔余额自动重算、银行对账与余额调节表 |
| 日清月结 | 逐日收支汇总、盘点数比对账实 |
| 固定资产 | 资产卡片、直线法月折旧、一键计提、购置入账 |
| 发票管理 | 进销项台账、查重、一键生成凭证、未入账预警 |
| 预算费控 | 期间 + 科目 + 项目预算，超支拦截 |
| 往来账 | 按单位归集发票 / 收付款 / 分录，逐笔余额、对账单（Word/Excel） |
| 期末结账 | 8 项检查清单、结转损益、年度结转（4103→4104） |

### V2.5+ 效率与分析工具

- **凭证模板**（一键套用）、**凭证连续套打**（人民币大写 + 签字栏）、**凭证合规体检**（断号 / 重号 / 跨期）
- **全局搜索**、**待办中心**（8 类待办自动汇总）、**对账单批量导入**（预览 + 查重）
- **现金流量表正表**（经营 / 投资 / 筹资）、**10 项财务比率 + 健康度评分**、**同比环比趋势**
- **坏账准备计提**（账龄比例可配、防重复）、**往来催收清单**、**报表快照归档**

### V2.8+ 工作台（28 项功能）

| 工作台 | 内容 |
|---|---|
| 会计工具箱 | 辅助核算维度、多期试算对比、待摊费用摊销、凭证编号规则、会计估计变更留痕、附件缺失检查、科目使用分析 |
| 出纳工作台 | 现金盘点（按面额）、票据台账、多账户余额、资金日报、付款审批分级、未来资金预测、现金限额 |
| 架构审计中心 | AST 架构扫描、评分卡、接口清单与耗时、依赖矩阵、代码异味、运行时健康 |
| 安全中心 | RBAC 操作员与角色、会话登录（失败锁定）、敏感操作审计、请求限流、输入安全扫描、数据脱敏、CSRF |

安全策略**默认只观测不阻断**，可在安全中心开启。

### 税务中心（V2.10，税额与税负率统一两位小数）

增值税销项 / 进项台账（按税率自动分组）、进项认证、增值税申报测算、附加税费（城建 / 教育 / 地方）、
**税负率两点区间控制**（低于下限提示少缴风险、高于上限提示多缴，百分比两位小数）、
企业所得税季度预缴（小微分段自动判定）、汇算清缴与业务招待费限额、
工资社保与**个税累计预扣法**、专项附加扣除、印花税计算器、征期日历。

### 报表与预测

- **三大报表**（资产负债 / 利润 / 现金流）+ 负数重分类 + 三大勾稽自动核对
- **在线经营分析报告**：管理层摘要、关键指标同比环比、利润构成瀑布图、盈利 / 偿债 / 营运 / 现金流四大能力分析、资产负债结构、风险提示
- **经营预测与展望**：未来 3 个月收入 / 净利润预测（±1σ 区间）、6 个月货币资金推演、资金安全月数、预算执行与年末推算、历史回测误差
- 报告为纯内联 SVG，**离线可用**，支持打印为 PDF / 导出独立 HTML
- **分析规则自定义**：流动性划分、现金流分类、比率阈值、账龄基准与计提比例，保存后全站生效；**所有工作台结果均为中文表格与信息卡，无需懂代码或 JSON**（见手册 §30）

## 架构

```
app/                        应用架构层
 ├─ bootstrap.py            组合根（唯一装配点，固定启动顺序）
 ├─ routing.py              Router 实例（168 条路由，可注入替换）
 ├─ ports.py                LedgerPort 协议 + SqliteLedger（SQL 唯一收口）
 ├─ container.py            Container + Facade 防腐层
 └─ extensions/             按业务域拆分（accounting / cashier / audit / security / tax）
core/                       领域层（零 SQL、零 HTTP、零反向导入）
 ├─ context.py              统一账套上下文（单一数据源）
 ├─ rules.py                规则引擎 + 功能影响图（39 节点 / 55 边）
 ├─ analytics.py            分析与预测服务（每个指标自带公式 / 数据源 / 口径）
 └─ report.py               图文报告渲染（纯内联 SVG）
server.py                   HTTP 适配层与核心报表实现
features.py / analytics_api.py  控制器（瘦）
public/js/*.js              前端 10 个模块（38 页面 / 42 页面注册）
tests/ + run_tests.py       5 套回归测试，203 项断言（含一键入口 / pre-commit / CI）
docs/                       用户手册（中 / 英）、需求规格说明书、需求跟踪矩阵
```

依赖方向单向：控制器 → `app` 抽象；领域层 → `LedgerPort`；零循环依赖（AST 持续可验证，见「架构审计中心」）。

## 快速开始

```bash
# 方式一：源码运行（Python 3.10+，无第三方依赖）
cd journal-pro
python server.py            # 浏览器打开 http://127.0.0.1:8765

# 方式二：Windows 双击
启动.bat                     # 自动打开浏览器，关闭窗口即停止服务

# 方式三：整站迁移包
# 系统管理 → 下载整站迁移包（含内置 Python 运行时），解压后双击 启动.bat
```

首次启动自动执行数据库迁移（schema_version 版本化，当前 v11）。

## 测试与质量保证

```bash
cd journal-pro
python run_tests.py             # 一键运行全部 5 套回归（203 项断言，约 10 秒）
python run_tests.py core tax    # 只跑指定套件
python run_tests.py --fast      # 快速模式（跳过最慢套件）
run_tests.bat                   # Windows 双击版
```

质量流程（保证后续修改不引入回归）：

1. **本地提交钩子**：`git config core.hooksPath .githooks` 后每次 `git commit` 自动运行回归，**测试不过不能提交**（已验证拦截有效；确需跳过用 `--no-verify`）；
2. **CI**：`.github/workflows/ci.yml` 在每次 push / PR 时于 GitHub Actions（Python 3.10 / 3.12 矩阵）自动运行全部回归；
3. 5 套测试 203 项断言全部基于临时账套，覆盖报表口径、税务两位小数精度、个税累计预扣、架构规则与安全开关。

详见 [docs/TESTING.md](docs/TESTING.md)（中英双语测试指南）。

## 数据安全与隐私

- 财务数据库（`data/journal.db`）、迁移包、运行时不进入版本库（见 `.gitignore`）；
- 审计日志与业务写入同事务，哈希链防篡改（`/api/audit/verify` 一键校验）；
- 敏感操作（删除 / 冲销 / 结账 / 权限变更）单独标记，支持导出。

## 技术栈

Python 3.10+ 标准库（http.server / sqlite3 / ast / json）· 原生 JavaScript SPA · 内联 SVG 图表（零 CDN）· Chart.js（监控大屏，可选）
