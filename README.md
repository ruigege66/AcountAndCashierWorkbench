# 会计出纳全流程管理系统（Journal Pro）

<div align="right">

**[🇬🇧 English](README_EN.md) ｜ 简体中文**

</div>

单机可部署的会计 + 出纳一体化系统：**Python 标准库 + SQLite，零第三方依赖**。
覆盖业务单据 → 审批 → 自动凭证 → 过账 → 日记帐 → 对账 → 期末结账 → 三大报表 → 经营分析与预测的完整链路，内置内控合规（不可变账本、审计哈希链、职责分离）。

> 版本：V2.16 ｜ 前后端分离（原生 JS SPA + REST API）｜ 数据库：SQLite（WAL）｜ 测试：12 套回归 490 项断言 + pre-commit + CI

### 税务中心（V2.16，税额与税负率统一两位小数）

增值税销项 / 进项台账（按税率自动分组）、进项认证、增值税申报测算、附加税费（城建 / 教育 / 地方）、
**税负率两点区间控制**（低于下限提示少缴风险、高于上限提示多缴，百分比两位小数）、
企业所得税季度预缴（小微分段自动判定）、汇算清缴与业务招待费限额、
工资社保与**个税累计预扣法**、专项附加扣除、印花税计算器、征期日历。

### 报表与预测

- **三大报表**（资产负债 / 利润 / 现金流）+ 负数重分类 + 三大勾稽自动核对
- **在线经营分析报告**：管理层摘要、关键指标同比环比、利润构成瀑布图、盈利 / 偿债 / 营运 / 现金流四大能力分析、资产负债结构、风险提示
- **经营预测与展望**：未来 3 个月收入 / 净利润预测（±1σ 区间）、6 个月货币资金推演、资金安全月数、预算执行与年末推算、历史回测误差
- 报告为纯内联 SVG，**离线可用**，支持打印为 PDF / 导出独立 HTML
- **分析规则自定义**：流动性划分、现金流分类、比率阈值、账龄基准与计提比例，保存后全站生效；**所有工作台结果均为中文表格与信息卡，无需懂代码或 JSON**（见手册 §30）

## 架构

```
app/                        应用架构层
 ├─ bootstrap.py            组合根（唯一装配点，固定启动顺序）
 ├─ routing.py              Router 实例（168 条路由，可注入替换）
 ├─ ports.py                LedgerPort 协议 + SqliteLedger（SQL 唯一收口）
 ├─ container.py            Container + Facade 防腐层
 └─ extensions/             按业务域拆分（accounting / cashier / audit / security / tax）
core/                       领域层（零 SQL、零 HTTP、零反向导入）
 ├─ context.py              统一账套上下文（单一数据源）
 ├─ rules.py                规则引擎 + 功能影响图（39 节点 / 55 边）
 ├─ analytics.py            分析与预测服务（每个指标自带公式 / 数据源 / 口径）
 └─ report.py               图文报告渲染（纯内联 SVG）
server.py                   HTTP 适配层与核心报表实现
features.py / analytics_api.py  控制器（瘦）
public/js/*.js              前端 10 个模块（38 页面 / 42 页面注册）
tests/ + run_tests.py       12 套回归测试，490 项断言（含前端完整性 20 项）
docs/                       用户手册（中 / 英）、需求规格说明书、需求跟踪矩阵
```

依赖方向单向：控制器 → `app` 抽象；领域层 → `LedgerPort`；零循环依赖（AST 持续可验证，见「架构审计中心」）。

## 数据正确性加固

- **备份恢复不回退规则**：恢复备份时曾硬编码重建旧版账本触发器，导致 018 迁移修好的「演示数据可清理」规则被悄悄回退。现改为从数据库读回触发器原始 SQL 原样重建，并在同一事务内完成——任一步失败整个恢复回滚，数据库不会处于无保护状态。
- **输入边界统一校验**：金额拒绝非数值 / 无穷大 / 超大值并给出中文提示；日期必须是真实存在的 `YYYY-MM-DD`；资产原值须为正、残值率 0~1、使用月数 1~600。避免脏期间（如 `not-a-d`）和 `inf` 金额污染报表。合法业务不受影响。

## 2026 增值税一般纳税人认定预警

按 2026-01-01 施行的《中华人民共和国增值税法实施条例》：**连续不超过 12 个月**经营期内累计应征增值税销售额超过 500 万元，即应办理一般纳税人登记，不再适用小规模纳税人（不是自然年度累计）。

系统按「实质性业务收入」（已过账、非结转凭证的营业收入）逐月滚动扫描任意连续 12 个月窗口取最大值，并同时核对发票销项口径、提示账票差异；达到 60% 提醒、达到 80% 升级为中级、超标为高风险，给出差额、预计达标月份与办理建议。风险预警页有中文卡片与近 12 个月明细表，标准、提醒线、当前登记身份都可在界面调整；设置为「已登记一般纳税人」后不再预警。该身份只控制合规预警，不影响税务中心的税率计算。

## 测试与质量保证

```bash
cd journal-pro
python run_tests.py             # 一键运行全部 12 套回归（490 项断言，约 16 秒）
python run_tests.py core tax    # 只跑指定套件
python run_tests.py --fast      # 快速模式（跳过最慢套件）
run_tests.bat                   # Windows 双击版
```

质量流程（保证后续修改不引入回归）：

1. **本地提交钩子**：`git config core.hooksPath .githooks` 后每次 `git commit` 自动运行回归，**测试不过不能提交**（已验证拦截有效；确需跳过用 `--no-verify`）；
2. **CI**：`.github/workflows/ci.yml` 在每次 push / PR 时于 GitHub Actions（Python 3.10 / 3.12 矩阵）自动运行全部回归；
3. 12 套测试 490 项断言全部基于临时账套，覆盖报表口径、税务两位小数精度、个税累计预扣、架构规则与安全开关。

**数据安全与索引**（迁移 019）：每天首次启动服务会往 `data/backups/` 生成一份 JSON 备份（含 24 张业务表），原子写入、同日不重复、只保留最近 7 份；没有后台线程、没有定时器，失败只打印一行且绝不阻止启动。备份目录已加入 `.gitignore`，财务数据不会进版本库。同时清理了两条重复 / 冗余索引（`journal_date` 重复建了两次、`vouchers(period)` 是复合索引的最左前缀），写入略快、库略小。

**加载性能**（不碰视觉、不增加运行时重绘）：静态资源用内容哈希 ETag 做协商缓存，文件没变返回 304，不再每次刷新重下 535 KB；API 响应仍强制 `no-store`，数据永不被缓存。首页 7 个数据请求改为 `Promise.all` 并行，首屏不再逐次等待。前端 28 处静默 `catch {}` 统一改为 `warn()` 留控制台线索，避免"演示数据没清干净"这类问题再被吞掉。

**跨功能联动测试**（`test_linkage.py`，100 项）：其余套件验证「单个功能算得对」，这一套验证「改了 A，B/C/D 是否跟着变」。它一次采集 20 个下游模块的读数指纹，执行一个上游写操作后再采一次，自动比对被联动影响的模块集合。覆盖 18 组链路：单据审批→结算→自动凭证→出纳流水→三表→比率→经营报告、发票→销项/进项→认证抵扣→应纳税额→附加税→税负率、坏账/折旧计提传导、驳回/作废/超预算/职责分离被拒时下游零污染、重复过账与重复计提的幂等、影响链声明与真实数据对齐、演示数据一键清空的完全复原。

## 数据安全与隐私

- 财务数据库（`data/journal.db`）、迁移包、运行时不进入版本库（见 `.gitignore`）；
- 审计日志与业务写入同事务，哈希链防篡改（`/api/audit/verify` 一键校验）；
- 敏感操作（删除 / 冲销 / 结账 / 权限变更）单独标记，支持导出。

### 七流工作台与岗位视角（V2.16）

系统按会计调研表组织：**11 项工作 × 7 条流（数据 / 资金 / 工作 / 执行 / 管控 / 价值 / 合规）× 5 类岗位 × 3 级能力进阶**。首页「我的工作」进入任一工作台，七个页签分别展示该条流的节点链、系统入口与法规依据；「岗位与能力进阶」页按岗位给出七流核心动作与成长路径。详见 [三表调研综合分析](journal-pro/docs/三表调研综合分析.md) / [English analysis](journal-pro/docs/Survey_Analysis_EN.md)。

首页提供**一键载入演示数据**（51 条 / 30 张表，覆盖单据、凭证、发票、合同、审计、税务、宏观、工作流），演示完可一键清空，不影响自有数据。
